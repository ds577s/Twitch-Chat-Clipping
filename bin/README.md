Put external tools here if they aren't on your PATH. The clipper looks in this folder first.

- `TwitchDownloaderCLI.exe`: https://github.com/lay295/TwitchDownloader/releases
  (the `TwitchDownloaderCLI-<version>-Windows-x64.zip` asset). Tested with 1.56.5.
- `ffmpeg.exe`: optional here if it's installed with `winget install Gyan.FFmpeg`.

Everything in this folder except this file is git-ignored.
